# Чек-лист функционального тестирования "Online Bookstore"

## Модуль 1: Аутентификация и Регистрация
- [ ] **CP-01 (Позитив):** Успешная регистрация нового пользователя с валидными данными (18+ лет, правильный масочный телефон РБ).
- [ ] **CN-01 (Негатив):** Ошибка регистрации при возрасте пользователя младше 18 лет.
- [ ] **CN-02 (Негатив):** Ошибка регистрации при неверном формате телефона (например, буквы вместо цифр).
- [ ] **CN-03 (Негатив):** Ошибка регистрации при несовпадении введенных паролей.
- [ ] **CP-02 (Позитив):** Успешный вход в систему (Login) с корректным логином и паролем.
- [ ] **CN-04 (Негатив):** Ошибка входа при неверном пароле.

## Модуль 2: Каталог и Поиск
- [ ] **CP-03 (Позитив):** Отображение списка книг на главной странице с постраничной пагинацией (12 элементов).
- [ ] **CP-04 (Позитив):** Успешный поиск книги по названию.
- [ ] **CP-05 (Позитив):** Успешный поиск книги по имени автора.
- [ ] **CN-05 (Негатив):** Поиск несуществующей книги (отображение пустого списка без падения приложения).
- [ ] **CP-06 (Позитив):** Сортировка каталога по возрастанию и убыванию цены.

## Модуль 3: Корзина и Резервирование (Waitlist)
- [ ] **CP-07 (Позитив):** Добавление доступной книги (`status='a'`) в заказ (переход экземпляра в статус `r`).
- [ ] **CP-08 (Позитив):** Увеличение количества экземпляров книги в заказе при наличии свободных на складе.
- [ ] **CP-09 (Позитив):** Уменьшение количества экземпляров книги в заказе.
- [ ] **CN-06 (Негатив):** Попытка добавить книгу с нулевым остатком (автоматическое добавление в лист ожидания `Waitlist`).

## Модуль 4: Оформление заказа (Checkout)
- [ ] **CP-10 (Позитив):** Выбор самовывоза с указанием конкретного пункта выдачи (`PickupPoint`).
- [ ] **CP-11 (Позитив):** Выбор курьерской доставки с вводом адреса.
- [ ] **CP-12 (Позитив):** Успешное применение активного промокода (`PromoCode`) с пересчетом итоговой цены.
- [ ] **CN-07 (Негатив):** Ввод недействительного или архивированного промокода (вывод сообщения об ошибке).
- [ ] **CP-13 (Позитив):** Подтверждение заказа клиентом (переход в статус `p` - In process).
- [ ] **CP-14 (Позитив):** Отмена заказа клиентом в статусе New (`n`), возврат книги на склад (`status='a'`).

## Модуль 5: Панель сотрудников (Staff Panel)
- [ ] **CN-08 (Негатив):** Попытка обычного клиента получить доступ к URL `/order-management/` или `/import_books/` (редирект 302).
- [ ] **CP-15 (Позитив):** Просмотр списка активных заказов сотрудником, поиск заказа по имени или телефону.
- [ ] **CP-16 (Позитив):** Завершение заказа сотрудником (`complete_order`), перевод книги в статус «продано» (`s`).
- [ ] **CP-17 (Позитив):** Импорт книг через Google Books API по ключевому слову с загрузкой обложки.
- [ ] **CP-18 (Позитив):** Добавление новых экземпляров книги на склад (`add_instance`) с автоматической выдачей ожидающим из `Waitlist`.
- [ ] **CP-19 (Позитив):** Обновление данных книги сотрудником в панели управления.
- [ ] **CN-09 (Негатив):** Ввод недопустимых символов (например, скриптов или неверного формата цены) при обновлении книги (срабатывание валидации).
