# Отчет по тестированию верстки, адаптивности и кроссбраузерности

## 1. Визуальная часть и адаптивность
- **Целостность блоков:** Все основные блоки (`.container`, `.book_grid`, `.news`, карточки книг `.book_card`) сохраняют правильную геометрическую форму на экранах любых размеров.
- **Выравнивание по сетке:** Использован современный инструмент CSS Grid (`grid-template-columns: repeat(auto-fill, minmax(210px, 1fr))`), что обеспечивает идеальное адаптивное выравнивание карточек товаров.
- **Адаптивность:** Проверено с помощью эмулятора DevTools при ширине экрана от 320px (мобильные устройства) до 2560px (UltraWide). При сужении экрана до `<768px` срабатывают медиазапросы (`@media (max-width: 768px)`), перестраивающие сетку каталога и блоков новостей в вертикальный поток.

## 2. Интерактивные элементы
- **Ссылки и кнопки:** Все ссылки в навигации и карточках книг кликабельны. Кнопки панели управления имеют плавные анимации при наведении (`:hover`), нажатии (`:active`) и фокусе (`:focus-visible` с видимым контуром доступности).
- **Логотип и Favicon:** Клик по логотипу компании в шапке (`/`) успешно возвращает пользователя на главную страницу магазина. В теге `<head>` файла `layout.html` корректно подключена динамическая `favicon` на основе логотипа компании.
