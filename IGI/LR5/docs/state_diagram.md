# Диаграмма состояний сущности "Заказ" (Order State Diagram)

Данная диаграмма отображает жизненный цикл заказа (`Order`) в интернет-магазине: от момента добавления книги в корзину до его успешного завершения или отмены.

## 1. Начальное и конечное состояния
* **Начальное состояние:** *Корзина / Создание нового заказа* (в коде модели соответствует статусу `'n'` — *New*).
* **Конечные состояния:** 
  1. *Done* (`'d'`) — Заказ успешно выполнен и доставлен.
  2. *Cancel* (`'c'`) — Заказ отменен клиентом.

---

## 2. Перечень состояний (States)
1. **New (`'n'`) — Новый (В корзине):** Заказ создан автоматически при добавлении первой книги. Книги зарезервированы на складе (`BookInstance.status = 'r'`). Клиент может менять количество товаров, вводить промокод или отменить заказ.
2. **In process (`'p'`) — В обработке (Подтвержден):** Клиент заполнил адрес/пункт выдачи, применил промокод и подтвердил заказ (`confirm_order`). Заказ передан в обработку сотрудникам магазина. Изменение состава заказа блокируется.
3. **Done (`'d'`) — Выполнен (Завершен):** Сотрудник нажал кнопку «Завершить» (`complete_order`). Заказ выдан клиенту, книги перешли в статус продано (`s`).
4. **Cancel (`'c'`) — Отменен:** Заказ аннулирован. Резерв с книг снят, они вернулись в свободный статус (`a`).

---

## 3. События и условия на переходах (Transitions)

* **Переход 1: Создание заказа**
  * *Откуда:* Вне системы (Инициализация)
  * *Куда:* **New (`'n'`)**
  * *Событие:* Клиент нажимает кнопку «Добавить в заказ» (`add_to_orders`) на странице книги.
  * *Условие:* Наличие хотя бы одного свободного экземпляра книги на складе (`BookInstance.status == 'a'`).

* **Переход 2: Подтверждение заказа**
  * *Откуда:* **New (`'n'`)**
  * *Куда:* **In process (`'p'`)**
  * *Событие:* Клиент заполняет форму подтверждения заказа (`confirm_order`).
  * *Условие:* Выбран метод доставки (курьер с адресом или самовывоз с пунктом `PickupPoint`), заказ содержит товары.

* **Переход 3: Успешное завершение**
  * *Откуда:* **In process (`'p'`)**
  * *Куда:* **Done (`'d'`) [Конечное состояние]**
  * *Событие:* Сотрудник нажимает «Завершить заказ» (`complete_order`) в панели управления (`order_management`).
  * *Условие:* Пользователь имеет права сотрудника/администратора (`is_staff` или `employee`), заказ находится в обработке.

* **Переход 4: Отмена заказа**
  * *Откуда:* **New (`'n'`)**
  * *Куда:* **Cancel (`'c'`) [Конечное состояние]**
  * *Событие:* Клиент нажимает кнопку «Отменить заказ» (`cancel_order`).
  * *Условие:* Заказ находится строго в статусе `n` (New), изменения еще не подтверждены окончательно. С книг снимается резерв (`status = 'a'`).

---

## 4. Текстовая схема переходов

```text
       [Начало]
          │
          ▼  (Событие: Добавить книгу / Условие: Книга доступна)
    ┌───────────┐
    │ New ('n') │ ─── (Событие: Отмена заказа) ───► [ Cancel ('c' ) ] *Конечное
    └─────┬─────┘                                                    
          │
          ▼  (Событие: Подтверждение заказа / Выбор доставки)
    ┌───────────┐
    │In process │
    │   ('p')   │
    └─────┬─────┘
          │
          ▼  (Событие: Менеджер завершил заказ)
    ┌───────────┐
    │ Done ('d')│ *Конечное
    └───────────┘
