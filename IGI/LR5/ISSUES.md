## 2. Журнал дефектов и расхождений (ISSUES)

Ниже зарегистрированы расхождения и дефекты, выявленные в ходе сверки спецификации требований с работающим приложением.

### Issue #1: Отсутствие пагинации на странице результатов импорта книг
- **Описание:** При импорте книг через Google Books API (`import_books`) выдается фиксированное количество результатов без возможности постраничного просмотра, если результатов найдено много.
- **Шаги воспроизведения:** Перейти в панель импорта книг, ввести популярный запрос (например, "Python"), посмотреть на выдачу.
- **Ожидаемый результат:** Наличие элементов пагинации для удобства выбора книг.
- **Статус:** Открыт (Зарегистрировано как улучшение / минорный дефект).

### Issue #2: Кеширование и задержка при отображении погоды в шапке сайта
- **Описание:** Из-за особенностей работы стороннего API погоды (OpenWeatherMap) при частых обновлениях страниц возможны кратковременные задержки ответа сервера, если внешний сервис отвечает медленно.
- **Шаги воспроизведения:** Быстро обновлять страницы сайта при нестабильном интернет-соединении.
- **Ожидаемый результат:** Запрос погоды должен быть вынесен в асинхронный поток или кешироваться, чтобы не тормозить отрисовку шапки (`header_data`).
- **Статус:** Открыт.
