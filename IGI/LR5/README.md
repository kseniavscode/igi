# Онлайн-книжный магазин (Bookstore Web App)

## 1. Назначение и целевые пользователи
- **Назначение:** Веб-приложение для поиска, заказа, покупки книг, управления складскими запасами, импорта литературы через внешние API, а также взаимодействия пользователей с администрацией (новости, FAQ, отзывы, вакансии).
- **Целевые пользователи:** 
  - *Клиенты (Покупатели):* ищут книги, оформляют заказы (самовывоз/курьер), используют промокоды, оставляют отзывы, задают вопросы в FAQ, управляют личным профилем.
  - *Менеджеры / Сотрудники:* обрабатывают заказы, управляют остатками на складе, добавляют экземпляры книг.
  - *Администраторы:* управляют каталогом книг, импортируют книги из Google Books API, настраивают рекламу (баннеры), отвечают на вопросы FAQ, просматривают аналитику продаж и финансовые отчеты.

## 2. Стек технологий
- **Язык программирования:** Python 3.10+
- **Фреймворк:** Django 6.0
- **База данных:** SQLite (в локальной разработке) / PostgreSQL (через Docker и `dj-database-url`)
- **Контейнеризация:** Docker, Docker Compose, Gunicorn
- **Библиотеки и утилиты:** Requests (интеграция с OpenWeatherMap и Google Books API), Matplotlib (генерация графиков продаж), Whitenoise (обработка статики), python-dotenv.

## 3. Архитектура
Проект построен на основе классического паттерна **MTV (Model-Template-View)** фреймворка Django и разделен на два основных приложения:
1. `store` — основное приложение каталога, заказов, корзины, клиентов и панели сотрудников.
2. `pages` — информационное приложение (о компании, новости, FAQ, вакансии, отзывы, промокоды).

*Схема связей (упрощенно):*
[Клиент/Браузер] -> [Django URL dispatcher] -> [Views (Логика)] -> [Models (ORM)] -> [БД (SQLite/PostgreSQL)]
                                                  ↳ [Templates (HTML/CSS)]
                                                  ↳ [External APIs (Google Books, OpenWeather)]

## 4. Перечень модулей и ответственность
- **`store.models` (Модели магазина):** Описывают сущности книг, авторов, жанров, экземпляров книг (`BookInstance`), клиентов, сотрудников, заказов (`Order`), пунктов выдачи и листа ожидания (`Waitlist`).
- **`store.views` (Контроллеры магазина):** Реализуют бизнес-логику каталога, корзины (резервирования), оформления и отмены заказов, панель менеджера, импорт книг и генерацию аналитических отчетов со статистикой.
- **`pages.models` & `views` (Информационный модуль):** Отвечают за статичные страницы, отзывы пользователей, систему вопрос-ответ (FAQ), новости и промокоды.
- **`store.forms` & `pages.forms` (Формы):** Валидация входных данных (регистрация с проверкой возраста 18+ и белорусских номеров телефонов, формы отзывов, добавление рекламы).
- **Контекст-процессоры (`core.context_processors`):** Динамическое добавление данных о погоде в Минске (OpenWeather API) и календаря в шапку сайта.

## 5. Точки интеграции
- **База данных:** PostgreSQL / SQLite (хранение пользователей, книг, заказов).
- **Внешние API:** 
  - *Google Books API* — поиск и импорт новых книг по запросу.
  - *Open Library Covers* — загрузка обложек книг по ISBN.
  - *OpenWeatherMap API* — получение текущей погоды для шапки сайта.
- **Файловая система:** Хранение загружаемых медиафайлов (обложки книг, аватары сотрудников, баннеры рекламы, логотипы компании).
